# 🔍 Person Search App

A minimalist web application powered by Google Programmable Search Engine for finding public profiles and information by name. Simple OSINT-style person search tool built with HTML, Tailwind CSS, and Google Custom Search.

🌐 **Live Demo:** [https://PLAMplam.github.io/person-search-app/](https://PLAMplam.github.io/person-search-app/)

---

## 💡 เทคนิคการค้นหาขั้นสูง (Search Tips)

เพื่อให้ค้นหาโปรไฟล์บุคคลได้แม่นยำยิ่งขึ้น แนะนำให้ใช้เทคนิคการค้นหาร่วมกับ Search Operators ดังนี้:

* **ค้นหาชื่อ-นามสกุลแบบตรงตัว:**  
  `"ชื่อ นามสกุล"` *(ใส่เครื่องหมายอัญประกาศ)*
* **เน้นค้นหาเฉพาะบน Facebook:**  
  `"ชื่อ นามสกุล" site:facebook.com`
* **เน้นค้นหาเฉพาะบน LinkedIn:**  
  `"ชื่อ นามสกุล" site:linkedin.com/in`
* **ระบุสถานที่หรือหน่วยงานเพิ่มเติม:**  
  `"ชื่อ นามสกุล" "ชื่อบริษัท/มหาวิทยาลัย"`
